# Contributing

Contributions are welcome under the MIT license.

1. Discuss substantial behavior changes in an issue.
2. Add a synthetic regression fixture and observable test.
3. Run `npm run check` on Node.js 20 or newer.
4. Keep the runtime dependency-free unless a dependency has a clear security and maintenance justification.
5. Update documentation and `CHANGELOG.md` for user-visible behavior.

Tests must never require credentials, external services, paid APIs, production data, or network access. By participating, contributors agree to follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
